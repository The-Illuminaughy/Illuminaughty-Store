# Illuminaughty® Store

Static GitHub Pages website for **www.illuminaughty.store**.

## Pages
- `/` — Homepage
- `/estore/` — Amazon affiliate catalog
- `/copyright/`
- `/terms-of-service/`
- `/privacy-policy/`
- `/eeo/`

## Shared shell
- `/shell/header.html`
- `/shell/footer.html`
- `/assets/css/site.css`
- `/assets/js/site.js`

- `IlluminaughtyLogo.webp`
- `IlluminaughtyBanner01.png`

The site uses the deployed Illuminaughty Apps Script web app for product data and customer signup.

## Notes
- Homepage banners all link to `/estore/`.
- Mobile eStore product cards scroll horizontally.
- Amazon affiliate disclosure appears only at the bottom of `/estore/` and in the Terms of Service.
